Option reference

'corr'Filtering by correlation. This is the default.
'conv'Filtering by convolution (kernel rotated 180° before sliding).
PBoundary extended by padding with constant value P (default 0).
replicateBoundary extended by replicating the outer border values.
symmetricBoundary extended by mirror-reflecting across the border.
circularBoundary extended by treating the image as one period of a 2‑D periodic function.
'full'Output is the same size as the extended (padded) image.
'same'Output is the same size as the input (default).
